# Desafio de Projeto: Design Patterns em Java

Este repositório foi criado para o desafio prático de Padrões de Projeto (Design Patterns) da DIO.

## Padrão Utilizado: Chain of Responsibility
O projeto implementa uma cadeia de aprovação de despesas corporativas em Java puro:
- **Gerente**: Aprova despesas de até R$ 1.000,00.
- **Diretor**: Aprova despesas de até R$ 10.000,00 caso ultrapasse a alçada do gerente.

## Como executar
Basta compilar e executar a classe `Main.java` na sua IDE de preferência.
